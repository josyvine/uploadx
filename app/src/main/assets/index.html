How to Use UploaderX

Getting Started: Account Management

The first step is to configure at least one Google Account. You can add multiple accounts to manage different channels.

  • Click Add New Account to create a new profile.
  • Give the account a memorable Nickname (e.g., "Gaming Channel").
  • Click Select client_secrets.json... to provide your credential file from the Google Cloud Console. This is required for the app to identify itself to Google.
  • Once the JSON file is selected, click the Authorize button. This will open a browser for you to sign in and grant the necessary permissions. Follow the on-screen instructions.
  • After successful authorization, the status will change to "Authenticated".

Configuring an Upload Task

On the main Config tab, you prepare the details for your video upload(s).

  • Select Account: Choose the authorized account you want to upload from.
  • Select Videos: Click Select Videos... to open the file picker. The videos you choose will appear in the film strip.
  • Title & Description: Fill in the metadata for your video.
  • Privacy Status: Choose whether the video should be private, unlisted, or public upon upload.

Using the Film Strip & Batch Mode

The film strip allows you to manage multiple videos for batch operations.

  • Single Mode (Default): Click on a video thumbnail in the film strip to select it for a single upload. The selected video will have a blue border.
  • Batch Mode: Go to the Terminal tab and click the "Batch Mode" button. Now, when you click videos in the film strip, you can select multiple videos (they will have a green border). When you start the upload, each selected video will be processed in its own task window.

Executing and Monitoring

Once everything is configured, click the Start Upload Process button.

  • The view will automatically switch to the Terminal tab.
  • For a single upload, a live log will show the progress.
  • For a batch upload, a grid of task windows will appear, each showing the progress for a specific video.
  • Use the buttons in the terminal header to Test Connection with the YouTube API or to Check for Updates to download the latest version of the automation script.
